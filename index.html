Descrive i comandi git basilari per la gestione di un progetto.

Ricerca comando:

Funzionalità

Comando Descrizione
git status controlla lo stato dei file modificati
git add [percorso_file] aggiunge la cartella o il file allo stage
git commit -m "[messaggio]" fa il commit dei cambiamenti e attacca un messaggio
git push pusha i vari commit sul repository di github
