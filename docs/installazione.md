# Installazione

Guida all'installazione del software.

## Clonare la repository

Aprire il terminale ed eseguire:

```bash
git clone https://github/CodeBanker000/project-docs.git

cd project-docs
```

## Primi Passi

1. da terminale utilizzare il comando `git clone` seguito dall'url del repository.
2. aprire il file index.html all'interno della cartella src  da browser, `doppio click` sul file o inserendo il percorso assoluto nella barra degl'indirizzi del browser
