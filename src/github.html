Catalogo Film

Catalogo Film è una piccola applicazione didattica per consultare una lista di films.

Funzionalità

  • Ricerca per titolo
  • Filtro per genere
  • Visualizzazione dettagli

Guida rapida

  1. Apri la pagina
  2. Scrivi una parola nella barra di ricerca
  3. Selezionare un film
  4. Leggi i dettagli
